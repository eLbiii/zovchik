# КомпМастер — Сайт сервисного центра по ремонту компьютеров

> Учебный проект: одностраничный сайт (лендинг) для сервисного центра «КомпМастер»

🔗 **Live Demo:** [https://eLbiii.github.io/zovchik](https://eLbiii.github.io/zovchik)

---

## 📋 О проекте

**КомпМастер** — это адаптивный одностраничный сайт (landing page) для сервисного центра по ремонту компьютеров и ноутбуков. Проект реализован в рамках учебного задания по дисциплине «Веб-разработка».

## 🚀 Функциональность

| Блок | Описание |
|---|---|
| **Hero** | Главный экран с заголовком, CTA-кнопками и статистикой |
| **О нас** | Информация о компании и преимуществах |
| **Услуги** | 6 карточек услуг с изображениями и описанием |
| **Цены** | 3 тарифных плана с выделенным «Популярным» |
| **Портфолио** | Автоматический слайдер с примерами работ |
| **Отзывы** | Карточки отзывов реальных клиентов |
| **Контакты** | Форма обратной связи с валидацией |

## 🛠️ Технологии

- **HTML5** — семантическая разметка
- **CSS3** — Flexbox, Grid, CSS-переменные, анимации
- **JavaScript (ES6+)** — без фреймворков, чистый Vanilla JS

## ✨ Особенности реализации

- 🌙 **Тёмная/светлая тема** — переключается с сохранением в `localStorage`
- 📱 **Полная адаптивность** — 4 брейкпоинта (1024px / 900px / 768px / 480px)
- 🎠 **Слайдер** — автопрокрутка каждые 4 секунды, пауза при наведении
- ✅ **Валидация формы** — RegExp-проверка email, минимальная длина полей
- 🔡 **Glassmorphism шапка** — `backdrop-filter: blur()` + sticky positioning
- 🎨 **CSS-переменные** — единая дизайн-система для обеих тем
