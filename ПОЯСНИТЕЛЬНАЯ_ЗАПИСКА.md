## 1. Цель проекта

Целью данного проекта является разработка адаптивного одностраничного сайта для сервисного центра по ремонту компьютеров и ноутбуков «КомпМастер» с применением технологий HTML5, CSS3 и JavaScript (ES6+) без использования сторонних фреймворков и библиотек.

## 2. Задачи

В ходе выполнения проекта были поставлены следующие задачи:

1. Разработать семантическую HTML-разметку в соответствии со стандартами HTML5
2. Реализовать адаптивный дизайн с поддержкой мобильных устройств
3. Создать систему CSS-переменных для управления дизайн-токенами
4. Реализовать переключение светлой и тёмной темы
5. Разработать интерактивный слайдер с автопрокруткой
6. Реализовать клиентскую валидацию формы обратной связи
7. Обеспечить кроссбраузерную совместимость

## 5. Структура страницы

Сайт состоит из следующих блоков:

### 5.1 Шапка (Header)
Липкая шапка (`position: sticky`) с эффектом размытия стекла (`backdrop-filter: blur`). Содержит логотип, навигационное меню, кнопку переключения темы и адаптивное бургер-меню для мобильных устройств.

### 5.2 Главный экран (Hero)
Первый экран с тёмным градиентным фоном, точечным паттерном и двухколоночной сеткой. Включает: бейдж, заголовок `<h1>`, подзаголовок, две CTA-кнопки («Оставить заявку» и «Наши услуги»), блок со статистикой и изображение команды.

### 5.3 О нас
Двухколоночный блок с фотографией мастера и текстом, перечнем ключевых преимуществ в виде маркированного списка.

### 5.4 Услуги
Сетка из 6 карточек (`CSS Grid`, `auto-fit`) с изображениями, заголовками и описаниями. При наведении карточка поднимается и изображение слегка масштабируется — реализовано через CSS-анимации.

### 5.5 Цены
Три тарифных плана: «Базовый», «Стандарт» (выделен как популярный) и «Премиум». Центральная карточка масштабирована (`scale(1.05)`) и стилизована в цвет акцента.

### 5.6 Портфолио (Слайдер)
Слайдер с 5 слайдами, точками-навигаторами и кнопками «вперёд/назад». Реализована автопрокрутка (интервал 4 сек.) с паузой при наведении курсора. Навигация по точкам и кнопкам сбрасывает таймер автопрокрутки.

### 5.7 Отзывы
Сетка из 4 карточек с рейтингом (звёздочки), текстом и блоком автора (аватар с инициалом + имя + услуга).

### 5.8 Контакты
Двухколоночный блок: слева — контактные данные и иконки социальных сетей (SVG), справа — форма обратной связи.

### 5.9 Подвал (Footer)
Строка с копирайтом на тёмном фоне.

## 6. Реализованный функционал

### 6.1 Переключение темы
- При загрузке страницы считывается сохранённое значение из `localStorage`
- При клике на кнопку `[🌙/☀️]` атрибут `data-theme` у тега `<html>` переключается между `light` и `dark`
- Все цвета объявлены через CSS-переменные (`:root` и `[data-theme="dark"]`), поэтому тема меняется мгновенно для всех элементов
- Выбор сохраняется в `localStorage` и сохраняется между визитами

### 6.2 Адаптивное бургер-меню
- На экранах шире 768px — горизонтальная навигация
- На узких экранах — скрытое меню, раскрывающееся при нажатии на бургер-кнопку
- При клике на любой пункт меню оно автоматически закрывается
- Поддержка `aria-expanded` для доступности

### 6.3 Слайдер портфолио
- Переключение слайдов через `transform: translateX()` — без перерисовки DOM
- Генерация точек-навигаторов выполняется динамически через JavaScript
- Автопрокрутка реализована через `setInterval`, приостанавливается на `mouseenter`, возобновляется на `mouseleave`
- При ручном переключении таймер сбрасывается через `clearInterval + setInterval`

### 6.4 Валидация формы
- **Имя**: минимум 2 символа
- **Email**: проверка RegExp-паттерном `/^[^\s@]+@[^\s@]+\.[^\s@]{2,}$/` — исключает некорректные адреса вида `a@b` или `a@b.`
- **Сообщение**: минимум 5 символов
- Ошибки отображаются через CSS-класс `invalid` на родительском `.form-group`
- При вводе ошибка снимается в реальном времени (`input`-событие)
- При успешной отправке кнопка переходит в состояние `disabled` + текст «Отправка...», затем появляется зелёный блок-уведомление

## 7. Дизайн и вёрстка

- **CSS Grid** и **Flexbox** используются совместно: Grid — для многоколоночных секций, Flex — для элементов внутри строк
- **CSS-переменные** (`--primary`, `--bg`, `--text` и др.) образуют единую дизайн-систему, что упрощает поддержку и изменение темы
- **`clamp()`** применяется для адаптивных размеров шрифтов без медиа-запросов
- **Hover-эффекты**: подъём карточек (`translateY`), масштабирование изображений, свечение кнопок
- **Glassmorphism** в шапке: `backdrop-filter: blur(12px)` + полупрозрачный фон
- Иконки социальных сетей реализованы через инлайн **SVG** (без сторонних библиотек)

## 8. SEO и доступность

- Единственный `<h1>` расположен в Hero-секции
- Иерархия заголовков: `h1` → `h2` → `h3`
- Все изображения имеют атрибут `alt`
- Интерактивные элементы имеют `aria-label`
- Бургер-кнопка использует `aria-expanded`
- Навигация обёрнута в `<nav role="navigation" aria-label="...">`
- `<meta name="description">` заполнен для поисковой оптимизации
